Artifact 1: Financial Data Learning Assistant

Course: AIML-500 Machine Learning Fundamentals

Project Type: Generative AI / Chatbot Development

Try the Financial Data Learning Assistant

Introduction

The Financial Data Learning Assistant is an educational AI chatbot I developed during my AI Lab. It helps beginners understand basic stock market information through simple explanations, numerical examples, and practice questions.

Description

The assistant focuses on stock price, trading volume, market capitalization, shares outstanding, and financial data reliability. It can explain concepts in simpler language, demonstrate calculations, and ask questions to check the learner's understanding.

The chatbot provides educational information only. It does not recommend specific investments.

Objective

I wanted to create an AI assistant that makes financial concepts easier for beginners to understand. I chose this problem because it connects with my experience working in financial technology.

Process

I started by identifying the needs of complete beginners. I then used design thinking to define the problem and explore possible solutions. I selected an interactive chatbot because learners could ask follow-up questions and request simpler explanations.

Next, I created the assistant as a custom GPT in ChatGPT, with instructions for its explanations, calculations, practice questions, and safety requirements. I tested it using six scenarios, including basic financial explanations, calculations, quizzes, and investment-related questions.

The original assistant passed all six selected tests. However, it could not be shared externally. I addressed this by creating a separate ChatGPT Project with similar instructions, and I tested that version's response to an investment advice question.

Relevance to My Professional Goals

Results

The original assistant passed all six selected tests, covering explanation clarity, simpler language, calculation accuracy, interactive learning, investment-related safety, and market interpretation. The project-based version also behaved appropriately when asked for investment recommendations.

The assistant remains an educational prototype. Further testing would be needed before wider deployment.

Artifact 2: Machine Learning vs. Deep Learning

Course: AIML-500 Machine Learning Fundamentals

Project Type: Research and Comparative Analysis

Introduction

This artifact is a report I developed to compare traditional machine learning and deep learning using real-world applications. The project helped me understand how different AI approaches solve problems and why selecting the right technology matters.

Description

I examined two applications:

  • Apache SpamAssassin: An email filtering system that uses traditional machine learning techniques, including Bayesian classification.
  • LumineticsCore: A medical screening system that uses deep learning techniques to analyze retinal images for signs of diabetic eye disease.

I compared how these approaches work, their benefits, and their limitations.

Objective

My objective was to understand when traditional machine learning is more practical and when deep learning provides an advantage. I also wanted to learn how data characteristics, model complexity, and computing requirements influence technology decisions.

Process

I started by reviewing the differences between machine learning and deep learning in our course lesson. Next, I researched two real-world applications, examining how each system uses data and why its selected approach fits the problem. I also considered why the alternative approach might be less practical. Finally, I prepared a written report with a comparison table, explanations, and supporting references.

Artifact 3: Explaining Neural Networks Through Financial Transaction Monitoring

Course: AIML-500 — Machine Learning Fundamentals

Based on: Assignment 3.4 — Communicating for Learning

Skills Demonstrated: Deep learning fundamentals, technical communication, AI literacy, data reliability, and responsible AI use.

Objective

My objective was to explain how neural networks work in simple language that people without a technical background could understand. I wanted to show how neural networks process information, recognize patterns, and improve through training.

Overview: What Is This Artifact?

This artifact is based on my Communicating for Learning discussion. I used a financial transaction monitoring example to explain neural networks. This example connects my professional experience in financial technology with my growing knowledge of artificial intelligence.

A neural network is a mathematical model that learns patterns from examples. It uses connected artificial neurons organized into layers.

How Neural Networks Work

Imagine a bank using a neural network to identify unusual transactions that may require further investigation. The network processes information through three main types of layers:

  1. Input Layer: receives transaction information, such as the amount, time, and location.
  2. Hidden Layers: combine and analyze the information. Connections have numerical weights that help determine the importance of different patterns.
  3. Output Layer: produces a prediction, such as whether a transaction appears unusual and needs further review.

Figure 1. Simplified neural network used for explanation. This is an illustrative example of how a neural network could support transaction monitoring, not a functioning fraud detection system.

How Does the Network Learn?

I compare neural network training to a student learning through practice. First, the network receives examples with known answers. It makes predictions and compares them with the actual results.

During training, it adjusts its connection weights to reduce prediction errors. With repeated practice, the network can become better at recognizing patterns. However, its performance on new data must still be tested.

Process

I first used ChatGPT to help create a simple explanation of neural networks. I selected financial transaction monitoring as the example because it relates to my professional background. I organized the explanation into short sections covering the layers, training process, and limitations.

After reviewing the shorter draft, I expanded it to explain how neural networks learn and why training data quality matters. I also considered how to make the content more suitable for beginners through clear language, step-by-step explanations, and a visual diagram.
